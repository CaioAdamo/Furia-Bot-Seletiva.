# Furia-Bot-Seletiva.
Projeto criado para participação da seletiva de estágiario da FuriaTech.

Descrição do desafio: Criar um chatbot para os fãs de CS da FURIA.

Como utilizar: Abra o frontEND em um LiveServer do VSCODE, e no terminal inicialize os .json com o comando npm init -y, após isso só será necessário utilizar o comando node server.js, e caso hajam erros ao inicializar o server, tente utilizar o npm install para instalar as depêndencias.
